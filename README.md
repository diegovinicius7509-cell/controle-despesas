# Controle de Despesas Pessoais

Aplicação de linha de comando (CLI) desenvolvida em Python para auxiliar no gerenciamento e na organização de despesas
pessoais.

## Sobre o projeto

O Controle de Despesas Pessoais é um projeto desenvolvido com o objetivo de facilitar o acompanhamento dos gastos 
individuais, permitindo organizar despesas por categorias e consultar informações financeiras ao longo do tempo.

A proposta é oferecer uma ferramenta simples, organizada e funcional, que ajude o usuário a compreender melhor seus 
hábitos de consumo e tomar decisões financeiras mais conscientes.

Este projeto também faz parte do meu processo de aprendizagem em Engenharia de Software, com foco na aplicação prática 
dos fundamentos da linguagem Python e das boas práticas de desenvolvimento.

## Objetivos

- Desenvolver uma aplicação funcional utilizando Python.
- Aplicar conceitos de lógica de programação e estruturas de dados.
- Praticar a organização e a modularização de código.
- Implementar operações de cadastro, consulta, edição e exclusão.
- Trabalhar com persistência de dados em arquivos.
- Utilizar Git e GitHub para controle de versão e documentação.

## Funcionalidades planejadas

- [ ] Cadastro de categorias.
- [ ] Edição de categorias.
- [ ] Exclusão de categorias.
- [ ] Cadastro de despesas.
- [ ] Edição de despesas.
- [ ] Exclusão de despesas.
- [ ] Consulta individual de despesas.
- [ ] Filtros por categoria e período.
- [ ] Consulta de totais por categoria.
- [ ] Resumos financeiros diários, semanais, mensais e anuais.
- [ ] Armazenamento persistente em arquivos JSON.
- [ ] Validação de dados e tratamento de erros.

## Tecnologias e ferramentas

- **Python 3:** linguagem de programação.
- **Git:** controle de versão.
- **GitHub:** hospedagem e gerenciamento do repositório.
- **PyCharm:** ambiente de desenvolvimento.
- **JSON:** formato planejado para armazenamento dos dados.
